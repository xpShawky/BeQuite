## 4. Signature techniques
- **Transitions:** none in the edit; one virtual camera move and two shared-element morphs carry the whole film.
- **Typography:** ChatGPT-like sans, type-on per letter; small UI text.
- **Colour:** near-black + saturated blue horizon glow; the photo is the only natural colour.
- **Sound:** −14.1 LUFS, music with a steady beat (confidence 4.13, the steadiest in this batch), hits about every 0.68 s. No voice ("Thank you" in the transcript is a Whisper hallucination on music).

## 5. When to use this style
- Fits: AI tool promos where one prompt → one result tells the whole story; 8-12 s.
- Avoid when: the output is text or code (no single image to grow).
- Cost: low-medium. AE: one 2D camera (or a null with position/scale), shape layers for UI, a photo, glass via Fast Box Blur + inner stroke.

## 6. What to steal
1. **Send button becomes the result** (shared element), then zoom through it.
2. **Eclipse horizon glow** as a logo stage that becomes the floor of the UI.
3. For BeQuite: the "Enter" key of a terminal command grows into the finished artifact.
