# /bq-now - deprecated alias

This command was merged into **`/bequite short`** in BeQuite v4 (one-line orientation). Run that instead; it does the same thing with the per-work gates. This alias will be removed in the next major release.

When invoked: say that in one line, then run `/bequite short` with the same arguments.
