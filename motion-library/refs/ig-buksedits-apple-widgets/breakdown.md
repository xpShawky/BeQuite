## 1. The story in one line
"Introducing Widgets": a swirl of iOS widgets resolves into one Activity widget that fills, grows and hands off to a Music widget, ending on "Endless creativity" and the Apple logo.

## 2. Story shape
Title → hero swarm → one feature (Activity) → second feature (Music) → tagline → logo. One continuous shot.

## 4. Signature techniques
- **Transitions:** no cuts; continuity by morphing one container (pill → small → medium → music → small).
- **Typography:** SF Pro-like bold, per-letter blur in; gradient blue tagline on black.
- **Colour:** white stage with soft coloured blobs that change per feature (green/blue for Activity, pink for Music) = colour coding by feature.
- **Sound:** −14.2 LUFS, true peak +1.4 dBFS (over 0: clipped master or re-encode), 117.5 BPM; a licensed-sounding vocal song (transcript catches lyrics; song UNVERIFIED). Hits land on a 1.0 s grid at the end.

## 5. When to use this style
- Fits: feature drops, UI component showcases, 10-15 s square posts.
- Avoid when: Apple-trade-dress copying is risky for client work; use the grammar, not Apple's assets.
- Cost: medium. AE with UI rebuilt as shape layers (or Figma → AE via a plugin), counters via expressions, blob background via blurred shapes.

## 6. What to steal
1. **One container that keeps changing size class** instead of cutting between screens.
2. **Background colour follows the feature** (each feature owns a hue).
3. **Swarm-to-one**: open with many items, collapse to a single hero.
4. For BeQuite: a swarm of 55 command chips that collapse into one `/bq-auto` pill.
