# /bq-p5 - deprecated alias

This command was merged into **`/bq-auto phase=P5`** in BeQuite v4 (Phase 5 (memory + handoff)). Run that instead; it does the same thing with the per-work gates. This alias will be removed in the next major release.

When invoked: say that in one line, then run `/bq-auto phase=P5` with the same arguments.
