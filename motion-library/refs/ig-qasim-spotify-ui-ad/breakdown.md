## 4. Signature techniques
- **Transitions:** none in the edit (1 shot). Every change is a **blur + opacity + small Y offset** handoff inside the frame; elements share positions (logo ring → avatar ring, chip → next line).
- **Typography:** Spotify-like geometric sans (Circular-like, UNVERIFIED), white, mixed sizes; per-character blur-in with stagger.
- **Colour:** black with drifting green radial blobs; Spotify green only on accents.
- **Pacing:** one beat about every 1-1.5 s, 8.8 s total.
- **Sound:** −14.1 LUFS but LRA 12.9 LU (very dynamic), harmonic share 0.43 (SFX-heavy); four short silences at 2.88, 4.78, 5.32, 8.24 s: **UI sounds with gaps**, the silences are part of the rhythm.

## 5. When to use this style
- Fits: app UI promos, feature teasers, SaaS "is this smooth" posts; 6-15 s.
- Avoid when: the product needs a real workflow shown; it is all mood.
- Cost: low-medium. AE: text animators with blur, shape layers, Gaussian blur keyframes, a gradient background with turbulent displace. 1-2 days.

## 6. What to steal
1. **Blur-to-focus as the universal transition** (blur 40 → 0 px, opacity 0 → 100, Y +20 → 0, ease-out, 8-12 frames).
2. **Logo becomes UI**: the icon's ring turns into the first avatar/frame.
3. **In-place headline swap** ("Global Sound" → "Global Immersion").
4. **Silence gaps between UI hits** instead of a continuous bed.
