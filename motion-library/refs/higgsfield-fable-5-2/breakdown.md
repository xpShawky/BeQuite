# "Claude Fable 5.2 is live on Higgsfield" trailer: breakdown

**File:** `inbox/old/Higgsfield AI on X_ Claude Fable 5.2 is LIVE on Higgsfield ….mp4` · **Source:** Higgsfield post on X · **Length / format:** 90.13 s, 1920x1080, 24 fps · **Studied from:** 1.5 s contact sheet + 17 cuts + loudness.
**Category:** product launch trailer · AI-generated game footage · UI demo

## 1. The story in one line
One prompt, "Create game of the year about dinosaurs", and the agent researches, rigs, builds characters, gameplay, multiplayer, a shop and graphics, chapter by chapter.

## 2. Story shape
Cold open (action) → title → offer → **prompt → agent work → result**, repeated with escalating prompts → offer details → end card.

## 4. Signature techniques
- **Prompt-as-chapter-card:** each act starts with a typed prompt. Very clear structure for "AI does the work" films.
- **Agent status lines with precise numbers** as on-screen narration.
- **Escalation:** every prompt makes the result bigger.

## 5. Weaknesses (do not copy)
- **Sound mastered at −6.4 LUFS with true peaks of +3.6 dB:** clipped and crushed, no dynamics for 90 s (the loudness curve sits at −4/−5 the whole time). Social platforms turn it down anyway; it only sounds cheaper.
- **AI-video tells:** generic hero faces, glossy "everything is epic" grade, neon-lime UI accents, a pink "CANDY REX" gag, legal text dumped over footage.
- **Too long for the idea:** the gameplay chapter (36–58 s) runs long with little new information.

## 6. When to use this style
- **Fits:** "watch the agent build it" product films, MCP or agent tools, long-form launch trailers (60–90 s).
- **Avoid:** copying its loudness, its genre clichés, or its AI-footage look.

## 7. What to steal
1. **Prompt cards as chapter headings**: for BeQuite, the real commands (`/bq-clarify`, `/bq-plan`, `/bq-motion`) as chapter cards.
2. **Status lines with real numbers** ("55 commands · 35 skills · 7/7 checks passed").
3. **Escalation per chapter**: each command produces a bigger, more finished result.
