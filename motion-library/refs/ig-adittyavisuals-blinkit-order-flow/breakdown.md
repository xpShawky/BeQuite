## 1. The story in one line
A grocery order from search to doorstep in 10 seconds, told by one UI element that keeps morphing.

## 2. Story shape
App icon → search → products → place order → driver found → arriving → delivered → end card. The real user journey, compressed.

## 4. Signature techniques
- **Transitions:** 3 cuts only; the story is one element morphing (icon → pill → dash → button → card → toast → bubble). Each morph: scale/size change of a rounded rectangle with corner radius animated, content cross-faded inside.
- **Motion feel:** overshoot springs, slight 3D tilt on the toast; a ring pulse behind the active element.
- **Colour:** neutral grey stage, brand yellow and green only on the active element.
- **Sound:** −14.0 LUFS, LRA 1.8 (flat), harmonic share 0.83 (music bed carries it); 67 % of cuts on the beat grid but few SFX.

## 5. When to use this style
- Fits: any flow product (delivery, booking, checkout, deploy pipeline), 8-15 s, square or vertical.
- Avoid when: the flow has more than ~6 states.
- Cost: low-medium. AE shape layers with roundness keyframes, text swaps, a cursor; or Figma Smart Animate → screen capture. 1 day.

## 6. What to steal
1. **One container morphs through every state of the flow.**
2. **Progress bar inside a status card** as the tension beat.
3. For BeQuite: `/bq-auto` pill → "Plan approved" card → "Tests 42/42" bar → "Shipped" toast.
