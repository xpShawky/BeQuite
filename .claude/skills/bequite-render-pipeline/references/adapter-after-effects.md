# Adapter: After Effects from code

Most important first: **every frame is generated by script (no hand keys), so each change is "edit the .jsx → rebuild → stills → preview"; renders go through aerender only after the render plan is approved; purge caches before and after every render.** This made 14 versions of a 57 s film possible in about 2.5 days in the worked example.

- **Best for:** scripted 2D/2.5D motion graphics, kinetic type with text animators, a 3D camera over layers, real per-layer motion blur, 16-bit colour.
- **How an agent drives it:** ExtendScript (ES3) executed inside the already-open After Effects through `assets/ae/runae.js`; renders with the `aerender` CLI through `assets/ae/aerender.js`; review stills via `saveFrameToPng`. Computer use only for things scripting can't reach (a one-time UI setting the user makes).
- **Install / licence:** paid Adobe subscription; Windows or macOS; Node.js for the bridge; fonts installed in the OS.
- **Honest limits:** needs a running, licensed AE; ES3 (no `let`, arrow functions, native JSON); UXP plugin support was in beta in late 2026 and the ExtendScript end-of-life date was unannounced (UNVERIFIED — check Adobe's developer pages); disk cache and GPU memory hazards; RTL paragraph control from script UNVERIFIED.

## Setup (once per machine — the user does the settings)

1. **User ticks:** AE → Preferences → Scripting & Expressions → *Allow Scripts to Write Files and Access Network*. BeQuite never changes app or security settings itself.
2. **User caps the disk cache:** Preferences → Media & Disk Cache (e.g. 10 GB). Uncapped, it filled a system disk to 100 % twice (one session reached ~93 GB).
3. Copy `assets/ae/*` into the work's engine folder (e.g. `.bequite/work/<id>/assets/ae/`): `runae.js`, `aerender.js`, `aepath.js`, `lib/`, `build/`, `examples/`.
4. Check detection: `node assets/ae/runae.js --detect` prints the AfterFX and aerender paths. Override with env `BEQUITE_AE_PATH` (Windows: `AfterFX.com`, its `Support Files` folder or the version folder; macOS: the `Adobe After Effects <ver>.app`). `BEQUITE_AERENDER_PATH` overrides aerender. Auto-detect looks in `%ProgramFiles%\Adobe\Adobe After Effects *` (newest year, non-beta first) and `/Applications/Adobe After Effects *`.
5. Install the brand fonts in the OS before building; refer to them by PostScript name in `K.config({F: {...}})`.
6. Prove the chain: `node assets/ae/runae.js assets/ae/examples/hello_film.jsx --timeout 300` → stills in `build/stills_hello/`.

## The loop

```bash
node ae/runae.js ae/build_v3.jsx --timeout 900        # build inside the open AE; prints {"ok":…, "result":…}
python <render-pipeline>/scripts/contact_sheet.py sheet.png ae/build/stills/*.png --cols 4
node ae/aerender.js --project ae/build/film_v3.aep --rqindex 1 --purge     # only after RENDER_PLAN_APPROVED
```

- **macOS:** `runae.js` runs the wrapper through `osascript -e 'tell application "<Adobe After Effects ver>" to DoScriptFile "<path>"'` (AppleScript command from the AE scripting guide; not tested in this pack — UNVERIFIED).
- **Windows:** `AfterFX.com -r <wrapper.jsx>` runs in the open AE (starts AE if needed). Test with a tiny script first; some AE versions were reported to crash on `-r`.
- **Build script shape:** `$.evalFile` the libraries → `K.config({...tokens from Motion DNA})` → `K.newProject({name})` → each scene as a precomp → place scenes on a FILM comp at their start times → transitions → the voice as a timing-only layer → a delivery comp (e.g. 2K) → queue the render → save the .aep → stills.
- **Stills:** `K.stills(comp, [t1, t2, …], dir)`; pass the times explicitly every run (globals such as `STILLS` persist in AE's scripting engine between runs); `saveFrameToPng` is asynchronous — wait for the files. It renders like aerender (same camera behaviour), so it is a valid check.
- **Previews for the user:** 720p at the master's fps, small (ffmpeg recipe in `adapter-ffmpeg.md`).
- **Result JSON:** the script sets `RESULT`; `runae.js` writes `build/result.json` and prints it; exit 0 ok · 1 script error · 2 setup/timeout.

## The library (`assets/ae/lib/`)

- `core.jsx`: `K.config` (tokens), `K.newProject` (safe guard, 16 bpc), comps at 60 fps with motion blur (shutter 200°, 16 samples), named easing curves (`expo`, `inout`, `whip`, `in`, `soft`, `hold`) with the hold-key fix, `K.spring`, `K.drift`, `K.punch`, text layers and animators (`K.reveal`/`K.hide` by char/word/line), masks, shapes, the marching-ants guide element, a quiet living background (`K.bg`), cursor + click ripple, group helpers, `K.stills`.
- `type.jsx`: the kinetic-type toolkit (function map in `.claude/skills/bequite-kinetic-type/references/engine-recipes.md`).
- Style is never baked in: colours and fonts come from the Motion DNA via `K.config`.

**New-project guard (fixed):** the original guard recognised "our" project only by a one-digit version regex, so a clean, saved `…_v13.aep` was refused with "Another project is open" (confirmed by reading the code; not reproduced in AE). Now `K.newProject` refuses only when the open project has **unsaved changes** and is not this film's project (marker folder `K.PROJECT` or `o.filePattern`); a saved, clean project closes without loss; `{force: true}` discards changes on purpose.

## Delivery quality

- **Banding** in dark gradients: 16 bpc project (AE dithers on output) + render a larger delivery comp (e.g. FILM at 133.33 % inside a 2560×1440 comp, collapse on) + encode x264 `-crf 15 -tune grain -pix_fmt yuv420p`; add 0.5–1 % grain. 8 bpc + 1080p showed rings.
- **Native resolution:** keep full-res images inside a precomp scaled down (e.g. 50 %) with collapse on, so camera zooms sample source pixels.
- 60 fps, motion blur on; strong ease-out on arrivals; springs only on things that land (easing table: `.claude/skills/bequite-motion-director/references/motion-grammar.md`).
- Render silent picture with aerender (`-sound OFF`), mux the mastered audio with ffmpeg (`adapter-ffmpeg.md`).
- GPU render preferred if the user dislikes CPU fan noise; if GPU memory runs out (black frames late in the render), lighten comps first; CPU fallback via `app.project.gpuAccelType = GpuAccelType.SOFTWARE` (slow, loud).

## Traps (each cost real time)

| Symptom | Cause | Fix |
|---|---|---|
| AE disk cache fills the disk; aerender "out of disk space" | cache refills during build + render; a film left open in a viewer keeps caching | cap the cache (user setting); `aerender.js --purge` (purge before **and** after); close viewers |
| 3D camera does nothing to a precomp | **collapsed precomps ignore 3D cameras** (Classic and Advanced 3D) | build the zoomed comp at 2.5–3× size, place it at 1/2.5–1/3 scale, leave it **un-collapsed**; images inside may stay collapsed |
| zooms blurry | nested comp rasterised at its own size | same as above, or collapse when no camera is needed |
| moves feel "default", not eased | **hold-key ease bug:** a key with an outgoing hold lost its incoming ease | fixed in `K.keys` — keep the library's version |
| layer jumps when parented | **parenting after keys:** `layer.parent = x` compensates at the current time | parent before keying, or `setParentWithJump` once the parent is animated |
| `setValue` fails | the property has keyframes | parent to a null and animate the null |
| children ignore parent opacity / in-out | AE parenting passes transforms only | animate the children (`K.groupOp`, `K.groupSpan`) |
| **banding** rings in dark gradients | 8 bpc + upscaling | **16 bpc**, 2K delivery comp, grain, x264 `-tune grain` |
| black frames late in a GPU render | GPU memory | lighter comps; check every render with `qc_report.py`; CPU fallback |
| label invisible | background shape created after the label | create backgrounds first or `moveBefore` |
| property reference errors | adding a property invalidates earlier references | re-fetch by path (`K.gc`, `K.lastSel`) |
| dashed stroke wrong | dash slots fixed | add Dash, Gap and Offset before an Offset expression |
| removing all Time Remap keys hides the property | AE behaviour | add the new keys first, then delete the defaults |
| `STILLS` from a previous run reappears | globals persist in the scripting engine | pass times explicitly |
| JSON result has broken strings | the old json2 polyfill did not escape newlines | fixed in `lib/json2.jsx` |

## Re-timing to a new voice

Prefer moving the voice to the approved picture (`bequite-sound-voice` phrase sync). If the picture must move: one time-warp table (anchor word → film time) applied with Time Remapping on the scene precomps (piecewise-linear pairs) and to the SFX cue times, or shift whole sections with one offset variable.
